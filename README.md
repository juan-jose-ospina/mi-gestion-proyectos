# 📊 Mi Gestión Proyectos

Aplicación web para la gestión integral de proyectos. Permite organizar tareas, hacer seguimiento de cronogramas y visualizar el progreso del equipo de trabajo.

> **Estado del Proyecto:** En desarrollo activo.

## ✨ Características Principales (Planeadas/En desarrollo)

-   📋 **CRUD de Proyectos:** Crear, leer, actualizar y eliminar proyectos.
-   ✅ **Gestión de Tareas:** Asignar tareas a miembros del equipo con estados (pendiente, en progreso, completada).
-   👥 **Roles de Usuario:** Diferenciación entre administradores, líderes de proyecto y miembros.
-   📈 **Dashboard Visual:** Gráficos y tableros para ver el avance general.
-   🔐 **Autenticación Segura:** Sistema de login y manejo de sesiones.
